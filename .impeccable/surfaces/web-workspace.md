# 网页工作区 · 2026-09-29

Mode: Operate。继承用户已确认的暖纸与森林绿，不更换视觉方向。

范围：电脑／局域网模式的仪表盘、计划、小测与复盘、资料库、Agent、个人中心、画像、模型设置、登录和模式选择。内置研习室与拾错继续使用共享主题。本设备模式保留已完成的 APK 同源布局。

布局：电脑侧栏分类导航，窄屏横向分类导航。总览只显示概况与今日任务；所有原模块均可通过对应分类和“查看全部”找到。排序时显示完整列表并继续使用原持久化顺序。分类切换仅隐藏模块，不卸载表单，避免丢失输入。

实现：frontend/public/web-design.css 在共享 agent-design.css 之后加载。所有新规则限于网页工作区及相关表单页面。主题来自同一组语义变量。

验证：frontend/scripts/verify-web-ui.mjs 使用完全隔离的模拟接口及测试账号，不访问用户数据或调用付费模型。检查三种主题与 390/768/1440 视口、空数据与有数据、分类导航、输入保留、排序、账号设置返回路径。浏览器 UI 测试不宣称后端业务和实体手机已通过验收。
