### 三科研习室集成边界

登录 Agent 后点右上角“三科研习室”，可进入 Agent 内置副本；副本地址为 `/study-hub/index.html`，三科与资源页均有固定的“返回考研 Agent”入口。不会读取原站 `8767` 端口记录；旧数据需从原站导出、在副本导入。开发模式仍保存在当前浏览器；局域网模式首次进入会将当前账号的浏览器记录迁到电脑端 SQLite，之后自动同步。多个设备或标签页同时修改同一副本若发生版本冲突，会暂停上传并提示，不会静默覆盖。请定期备份，公用设备不要保留登录状态。

Agent 可以依据复制版的只读题库目录推荐科目、考点、年份和练习页面。在聊天中询问“整理分析我在研习室的错题”，会从当前账号记录提取各科统计、最多 10 道近期题库错题的作答与错因笔记、最多 5 条自定义错题，并发送到当前配置的对话模型，供其归纳错因和复习优先级；不发送整份备份，也不代交或修改作答记录。题库目录能匹配的错题会附研习室入口及选择题参考答案，其他练习题只作为个人记录分析，不推断标准答案。开发模式的原始记录在浏览器，局域网模式以电脑端快照为准；Agent 的回答会进入对话历史。题目与答案仍应在研习室页面核对；政治时政内容需查最新官方资料。原项目文件保持不动；副本单独修复了原静态包中被截断的 KaTeX 脚本以恢复数学公式显示。

本次集成验证：后端全量测试 71 项通过，前端生产构建通过；隔离浏览器检查三科与资源页、数学公式、英语/政治练习深链、手机宽度、账号切换后的本机记录分区，以及 Agent 聊天请求携带的错题统计。原 `kaoyan-study-hub` 工作树保持干净。

### 拾错复习集成边界

登录 Agent 后可从仪表盘右上角进入 `/mistake-review/index.html`。这是 `kaoyan-mistake-app-publish/site` 的内置副本，不调用原站。原站或其他端口的数据不会自动迁移；可在原站导出后，在副本中导入。局域网模式会把当前账号记录同步到电脑端 SQLite；开发模式仍只保存在当前浏览器。

询问 Agent 错题或学习建议时，会发送当前账号拾错记录的总数、待复习数、薄弱数和最多 10 条近期错题的截断文字字段给当前配置的对话模型；不发送图片或整份数据库。拾错副本的 AI 功能复用 Agent 模型配置和后端代理，不再单独保存 API Key。内置页面固定提供“返回考研 Agent”入口；局域网版记录同步规则与研习室相同。

2026-09-26 集成校验：前端生产构建通过，后端 77 项测试通过，拾错脚本语法检查与前后端本机地址检查通过。两个原项目未被本次集成修改。

## macOS 与 Linux 启动

在一个终端中安装并启动后端：

```bash
cd kaoyan-agent/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 127.0.0.1 --port 8003
```

在另一个终端中安装并启动前端：

```bash
cd kaoyan-agent/frontend
npm install
npm run dev
```

打开 Vite 显示的地址（默认 `http://127.0.0.1:5175`）。后端健康检查为 `http://127.0.0.1:8003/api/health`。

依赖装好后，macOS 可在 Finder 双击项目根目录的 `启动考研Agent.command` 一键启动前后端；也可在终端运行 `./scripts/start-local.sh`。脚本会等待服务就绪并自动打开页面；新启动的服务会在该终端窗口持续运行，关闭窗口即可停止。重复运行会复用已经运行的服务。启动日志和进程号保存在 `.run/`。也可分别执行 `./scripts/start-backend.sh` 和 `./scripts/start-frontend.sh`。

本项目的 macOS 启动脚本会自动使用 `backend/.venv` 和 ChatGPT 应用内置 Node，不要求系统全局安装 `uvicorn` 或 `npm`。

cd kaoyan-agent\backend

也可双击 `scripts\start-backend.bat` 与 `scripts\start-frontend.bat`（首次仍需先安装依赖）。

## 两种使用方式（移动设备优先）

网页版首次打开会让用户选择“本设备独立模式”或“电脑局域网模式”，之后可在首页切换；Android APK 固定进入本设备模式。两种模式的数据命名空间互不覆盖，也不会自动双向同步。独立模式可使用 Agent 本机画像、今日任务、读取研习室和拾错记录的联网对话，以及两个内置学习应用，并在首页导出/导入合并 JSON 备份。网页版直连模型要求接口允许跨域，APK 使用原生网络通道；API Key 只存于当前会话，不进入备份。资料库、模拟测试、周/阶段计划与账号功能仍需电脑后端。电脑模式保留这些完整功能，在个人中心可导出/导入同格式备份；导入后重新打开两个内置页面完成同步，若提示冲突先保留备份文件。

独立模式的记录保存在当前手机或平板浏览器，浏览器清理站点数据会删除记录，必须定期导出。首页会显示当前地址的离线缓存状态；只有显示“离线资源已缓存”时才可依赖断网打开已缓存页面。生产构建已加入可安装网页应用的静态资源缓存；在 HTTPS 或设备自身 `localhost` 的安全来源首次联网安装后，隔离浏览器已验证断网仍能打开首页、数学研习室和拾错。普通 `http://电脑局域网IP:8003` 在手机浏览器不是安全来源，不能注册离线缓存，所以该地址只能按电脑局域网模式在线使用。手机独立安装还需要 HTTPS 分发或原生容器，实体 iOS/Android 尚未验收；不要把当前网页误称为已上架的原生 App。

### 电脑运行、手机和平板访问

这是由用户自己的电脑运行的局域网版，不是云服务，也不是已打包的 `.app` / `.exe` 安装包。电脑上的 Agent 包含研习室和拾错副本；手机和平板通过同一 Wi-Fi 的浏览器访问电脑，电脑必须保持开机和脚本运行。

首次使用先安装上面的后端、前端依赖，并关闭原来的 `8003` 后端和 `5175` 前端。macOS 可双击 `scripts/start-lan.command`，或运行 `./scripts/start-lan.sh`；Windows 可双击 `scripts\start-lan.bat`。脚本会构建同源前端、升级数据库、首次生成强密钥并备份原 SQLite，然后在 `8003` 启动并打开电脑浏览器；终端会显示手机可用的 `http://电脑局域网IP:8003/`。首次切换密钥后，旧登录会话须重新登录。若防火墙询问，请只允许可信的家庭/私人网络。不要在公共 Wi-Fi、互联网或路由器端口映射上开放 `8003`；当前连接是 HTTP，账号密码和资料在局域网传输时未加密。

局域网版以电脑端 SQLite 为准。内置研习室、拾错在首次访问时会迁移当前浏览器的旧记录，之后改动自动同步；超过 10 MB 的副本（尤其含大量图片的拾错）会暂停同步并提示先导出、整理。多个标签页/设备并发修改同一记录可能冲突，遇到提示先从个人中心导出双方数据，再手动选择保留内容；不要直接清浏览器缓存。模型设置中的 `127.0.0.1` 指运行后端的电脑，本机 Ollama 仍需在电脑上运行；在线兼容 API 不需要用户手机安装模型。

换电脑时，先停止服务，用下文的数据目录脚本把 `data/` 复制到外部备份位置，同时安全保存 `.run/lan-secrets.env`（包含解密已保存模型 Key 所需密钥）。在新电脑安装相同项目及依赖后，先将备份恢复到新的、未使用的数据目录，确认完整性，再配置 `DATA_ROOT` 和 `DATABASE_URL` 指向恢复目录，并把密钥文件放回新项目的 `.run/`；首次启动前不要让脚本生成一组新密钥。备份里有账号与学习资料，勿直接上传到公开网盘。仅导出个人中心 JSON 不包括整个账号、资料文件与模型配置。

Windows 版的一键启动脚本尚未在实体 Windows 电脑验收；扫描 PDF/图片的本地 OCR 目前依赖 macOS Vision，Windows 上该部分仍需跨平台 OCR 实现与实机验证。不要把源码启动入口当作已完成的桌面安装包。

当前应用启动仍使用 `create_all` 兼容未经纳管的旧库；今后修改数据模型应新增 Alembic 版本文件并执行 `upgrade head`，不可依赖 `create_all` 修改已有列。数据迁移与应用升级前应停掉后端，并保留数据库和 `data/uploads`、`data/chroma` 的同一时间点备份。

完整数据目录的离线备份与恢复都使用同一脚本，目标必须是尚不存在的新目录。先停止后端，再在项目根目录运行；不要把备份目录放进 `data/` 内。恢复时先复制到新目录并校验，再决定是否手动切换 `DATA_ROOT`/`DATABASE_URL`，脚本绝不覆盖原目录。

```bash
cd kaoyan-agent
backend/.venv/bin/python backend/scripts/copy_data_dir.py data /绝对路径/kaoyan-backup-20260923
backend/.venv/bin/python backend/scripts/copy_data_dir.py /绝对路径/kaoyan-backup-20260923 /绝对路径/kaoyan-restored
```

脚本检查 SQLite 完整性，并复制上传文件及 Chroma 索引。隔离环境已完成实际备份恢复演练；正式数据尚未执行此操作。`.env` 不包含在数据备份中，尤其要另行安全保存 `MODEL_CONFIG_SECRET`，否则恢复后已保存的模型 API Key 可能无法解密。
如果 SQLite 文件不是默认的 `kaoyan.db`，两次复制都要加 `--database-name 文件名.db`。

使用临时 SQLite 数据库时，上传和 Chroma 默认跟随数据库文件所在目录；也可通过 `DATA_ROOT` 明确指定独立数据目录。正式数据库仍默认使用项目内的 `data/`。
